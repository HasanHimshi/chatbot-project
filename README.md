# Himshi AI EduBot v8

Desktop-only PHP + MySQL chatbot project.

## New in v8
- Admin login
- Dashboard analytics
- Settings page
- Training categories and active/inactive status
- Chat sessions and memory
- Feedback saving
- Shared navbar on all pages

## Run
1. Copy folder to `C:\xampp\htdocs\perfect_chatbot_project`
2. Start Apache and MySQL in XAMPP
3. Import `database.sql` into phpMyAdmin if needed
4. Open `http://localhost/perfect_chatbot_project/`

## Admin
Default login: `admin` / `admin123`
Change it from Settings after login.

## Database port
`db.php` uses port `3307`. Change to `3306` if your MySQL uses default port.
